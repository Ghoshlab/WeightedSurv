# WeightedSurv
This repository shows the R scripts needed to implement the methodology in the manuscript "A  weighted survival regression approach to incorporating external risk information" by Ghosh.  There is an example using the R language to implement the methodology with respect to data from a liver cancer study.  Here are the steps to running the code:

1. Download all the files in this repository and store them in the same working directory.
2. Start R or RStudio.
3. Run the hccweightedcode.R file.
